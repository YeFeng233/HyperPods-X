# 系统蓝牙列表设置入口直达

HyperPods-X 接入了 HyperOS 系统蓝牙设置列表，用户在系统设置中点击已绑定 AirPods 卡片右侧的箭头时，可以直接打开 HyperPods-X 的控制面板。

---

## 1. 作用域与准备

- **LSPosed 作用域**：勾选“系统设置”（`com.android.settings`）。
- **生效方式**：模块更新或首次启用后，重启系统设置进程（可在 App 内使用“重启作用域”）或重启手机。

---

## 2. 实现机制

1. **点击拦截**：HyperOS 设置应用中的蓝牙设备行由 `MiuiBluetoothDevicePreference` 承载。右侧的详情箭头（视图 ID `preference_detail`）在触发原生监听器前会先派发点击事件；
2. **身份与状态校验**：模块在回调中核对视图 ID、模块运行状态以及当前项的蓝牙物理地址。仅当地址与 HyperPods-X 已绑定的 AirPods 完全一致时，启动 `DeviceSettingsActivity` 并中断原生向导；
3. **安全回退**：
   - 点击整行进行连接/断开的操作不被拦截；
   - 未绑定的 AirPods、其他品牌的蓝牙设备，或启动出现异常时，均原样执行系统原生回调；
   - 系统蓝牙详情页内保留“HyperPods-X 高级设置”入口，方便随时调用。
4. **风格自适应**：无论在何处打开，界面都会无缝继承用户在“更多设置 → 外观”中选择的 UI 风格（miuix 或 iOS）。
