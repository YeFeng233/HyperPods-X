## HyperPods-X 0.4.7 预览版

超级岛改为分别展示左右耳：左侧是左耳图标和电量百分比，右侧是右耳百分比和右耳图标，不再显示充电盒。两张单耳图在构建时从原透明双耳素材拆分生成，保留原始像素与透明度。

左右耳各自使用实际电量，未知时显示“—”。底部原生弹窗和 App 中可查看左右耳与充电盒的完整信息。底部卡片始终保留充电盒区域，仅有缓存电量时明确标注“上次”。

已在 Xiaomi 17 Pro Max、HyperOS 4 和 AirPods 5 上通过原生超级岛截图验证。98 项现有测试通过，Android lint 无错误。更新后需重新加载“小米蓝牙”宿主进程或重启手机，以使用新的模块布局。

本版本要求 Android API 37，以及支持现代 API 102 的 LSPosed，沿用项目当前的测试签名。
