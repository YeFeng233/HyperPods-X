## HyperPods-X 0.4.9 预览版

在“更多设置 → 外观”切换界面风格。关闭为 **miuix风格**，开启为 **iOS风格**；默认沿用 miuix，选择会在重启后保存。切换后仍停留在更多设置，可以随时切回。

iOS 设计适配自 NEORUAA 的 PR #1，使用 Glasmio、SF Pro、玻璃导航和分组设置，提供音频与路径、控制与手势、无障碍、电池及空间音频页面。两种风格共用既有连接、设置回读和校准数据。系统蓝牙列表的快捷入口也会打开选中的界面。

源码构建使用固定 Glasmio 提交，执行 `python scripts/prepare-ui.py --fonts` 即可准备源码依赖和用户指定 SFWindows 版本的字体。字体只作为本机构建输入，不包含在 Git 源码中。详细构建说明见 `docs/UI-STYLES.md`。

miuix 首页的聆听模式新增最左侧“关闭”，空间音频改为“关闭／固定／头部追踪”分段滑条。普通开关按各自状态更新，保留页面和滚动位置。

接入 PR 的 HyperOS 融合设备中心适配，显示绑定耳机的电量，通过现有控制连接切换聆听模式与固定空间音频，“更多设置”进入所选风格的模块页面。聆听模式从左到右为“关闭／通透／自适应／降噪”。需要在 LSPosed 中额外启用“设备互联”（`com.milink.service`）并重启宿主；适配与应用界面风格无关。原生响铃查找沿用系统实现，其声音结果另行验证。

融合设备中心使用系统内置的双耳 AirPods 图片。切换聆听模式时保留原有按钮，只更新选中与可用状态；设置回读的短暂重连不再使整张卡片退回简化样式。四种模式、空间音频开关和设置入口已在目标手机上验证，使用者确认控件不再重载。

### 维护更新

- 使用 PR #1 提供的自适应启动图标，并在应用清单中启用圆形图标入口。
- 修复开盖后系统 A2DP/HFP 不自动回连的问题；真实开盖保留 HyperOS 快连组件的 profile 连接路径，预览仍保持展示-only。
- 目标真机确认开盖自动回连功能正常；本维护更新不改变版本号、`versionCode` 或现有测试签名。
