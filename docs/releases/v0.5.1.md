## HyperPods-X 0.5.1 发布说明

### 主要更新

- 在“更多设置 → 连接设置”新增“自动连接到此设备”开关，支持 miuix 与 iOS 两套界面。
- 开关状态持久化到应用配置，并同步到小米蓝牙宿主和原生 AirPods 弹窗流程。
- 关闭开关后，模块不再强制拉起 A2DP/HFP；系统仅按上次连接状态执行自动连接。
- 完善双界面共享设置目录、中文与英文资源，以及设置状态的本地化回读。
- 更新 miuix 设置页面结构与 Glasmio 导航 API，补充电量提醒、型号状态和连接诊断支持。

### 构建信息

- 应用版本：`0.5.1-dev-device-test`
- versionCode：`23`
- 最低系统版本：Android API 36（Android 16）
- LSPosed 作用域：`com.android.settings`、`com.xiaomi.bluetooth`、`com.milink.service`、`com.miui.securitycenter`

### 验证范围

- App 单元测试、协议测试与 Binder 通信测试通过。
- Android lint 无错误。
- `deviceTest` 构建通过，并验证 R8 保留 LSPosed 模块入口。
