## HyperPods-X 0.4.8 预览版

系统蓝牙列表中，点击已绑定 AirPods 卡片右侧的箭头，现在会直接打开 HyperPods-X 耳机设置。返回键回到蓝牙列表；其他设备继续进入原有页面。模块内的“音频与设备权限”仍可打开系统详情，调整 AAC、媒体/通话和权限。

本版同时包含此前预览版的电量界面调整：超级岛左右两侧分别显示单耳图片和对应电量，仅底部完整电量卡片保留充电盒。充电盒实时电量优先，只有缓存时标注“上次”，完全未知时显示“—”。

首次使用请在系统蓝牙配对，并在 HyperPods-X 中绑定耳机；仅按绑定地址提供快捷入口。需要支持现代 API 102 的 LSPosed，作用域包括“系统设置”和“小米蓝牙”。更新后重新加载对应宿主进程或重启手机。

当前测试范围为 Xiaomi 17 Pro Max、HyperOS 4 和 AirPods 5，最低 Android API 37，沿用项目当前测试签名。

已在真机验证 AirPods 箭头直达、返回蓝牙列表、小米耳机原生入口和模块内系统详情入口。98 项现有测试通过，Android lint 无错误。此轮没有新增音频试听或耳机配置写入。
