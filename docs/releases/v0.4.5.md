## HyperPods-X 0.4.5 预览版

这一版将空间音频整理为“关闭、固定、头部追踪”三个选项。首页和空间音频页面使用相同的控件，切换结果以系统回读为准。固定模式不需要校准；头部追踪沿用已保存的三轴校准，切换到其他模式时会停止姿态订阅并清理传感器，也支持在启动过程中取消。

同时保留此前已经接入的 HyperOS 原生开盖弹窗与超级岛、左右耳和充电盒电量、系统蓝牙设置入口、自动入耳检测、通透/自适应/降噪、高级设置、EQ 和对话感知媒体降音。提示音量范围为 15–100；目标设备上的滑动调音已由使用者确认正常。

当前验证设备为 Xiaomi 17 Pro Max、HyperOS 4 和 AirPods 5。应用要求 Android API 37 及支持现代 API 102 的 LSPosed，作用域为“系统设置”和“小米蓝牙”。其他设备和系统版本还没有完整验证。

对话感知的轻声识别、长期头追漂移、后台功耗和复杂中断场景仍需继续完善；部分高级选项目前只完成配置写入验证。完整使用说明与测试范围见仓库 README 和 `docs/TEST-REPORT.md`。

附件中的 APK 是经过 R8 优化并签名的 `deviceTest` 预览包，沿用项目当前测试签名。源码 ZIP 对应该次构建的提交，文件校验值、公开签名指纹和测试统计分别见 `SHA256SUMS` 与 `build-info.json`。
