## HyperPods-X 0.4.6 预览版

这一版将自适应降噪从原来的三档调节改为 LibrePods 的整合式连续滑条。进入自适应模式后，可以在 0～100 之间拖动，向右增强降噪，调节过程会持续发送变化的目标值。

滑条可以继续拖动，无需等待每个位置的同值回执，也不再为每个位置重连控制通道。界面分别显示已发送的目标和耳机实际回读，避免在尚未确认时把目标当作设备当前值。快速反向拖回原值也会正确替换前一个目标。

控件适配了 Miuix 配色、深色模式、窄屏、大字体、键盘与无障碍操作，也支持从右向左的布局。组件来源、GPL 许可和改动说明见仓库第三方声明。

使用者已在 Xiaomi 17 Pro Max、HyperOS 4 和 AirPods 5 上测试新版滑条，并确认正常。App 与协议共 98 项测试通过，Android lint 无错误。逐项中间值回包、断线后的持久化和其他型号仍未完整验证。

本版本要求 Android API 37，以及支持现代 API 102 的 LSPosed。附件提供沿用项目测试签名的 R8 优化 APK、对应提交的源码 ZIP、构建记录和 SHA-256 校验文件；可以覆盖安装此前的同签名测试版。
