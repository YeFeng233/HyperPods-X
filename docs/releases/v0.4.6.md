## HyperPods-X 0.4.6 预览版

这一版合并了上游参考 LibrePods 实现的连续强度发送策略。Glasmio 聆听模式中的子滑块可以在 0～100 之间连续调节，向右增强降噪，拖动时持续发送变化的目标值。

无需等待每个位置的同值回执，也不再为每个位置重连控制通道。界面立即响应操作，发送目标和耳机实际回读分别保存，快速反向拖回原值也会替换前一个目标。发送失败或断开连接后恢复实际状态。

页面继续使用 Glasmio 组件、导航和 SF Pro，保留深色模式、大字体、键盘、无障碍及从右向左的布局。来源与许可说明见仓库第三方声明。

上游报告使用者已在 Xiaomi 17 Pro Max、HyperOS 4 和 AirPods 5 上确认使用正常。该策略未改变 AACP 包格式，发送成功与耳机确认仍有区别；逐项中间值回包、断线后的持久化和其他型号仍需验证。

本版本要求 Android API 37，以及支持现代 API 102 的 LSPosed。附件提供沿用项目测试签名的 R8 优化 APK、对应提交的源码 ZIP、构建记录和 SHA-256 校验文件；可以覆盖安装此前的同签名测试版。
