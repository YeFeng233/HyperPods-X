# 日志收集与导出

在 **更多设置 → 导出日志** 中选择保存位置，生成 `HyperPods-X-logs-日期-时间.zip`。miuix 和 iOS 两种风格都提供此入口；无需额外存储权限。导出期间按钮会暂时禁用，完成或失败后显示结果，也可以在系统文件保存界面取消。

确认保存后，导出任务在应用级作用域执行，切换界面风格、旋转屏幕或页面重建不会中断保存。

应用启动后自动记录连接、开盖、设置回读、空间音频、对话感知及错误信息。应用日志保存在私有目录，最多 4 个 256 KiB 文件，旧记录自动轮转；后台写入队列有容量上限。应用异常退出时尝试同步保存当前日志，再交回 Android 原有异常处理器。

ZIP 包含：

- `diagnostics.json`：应用和系统版本、当前连接状态、电量、设置回读及功能诊断；不导出耳机名称、地址或私有偏好。
- `app-history.log`：跨应用重启保留的最近日志，最多 1 MiB。
- `app-session.log`：当前进程最近的日志，最多 64 KiB，包含可能尚未写入磁盘的记录，与历史文件会有部分重叠。
- `hosts/`：当前运行的系统设置、小米蓝牙和设备互联进程中，本模块自身的日志；每个进程最多 64 KiB、1000 条。
- `collection-status.txt`：各宿主是否返回日志。未运行、作用域未开启或更新后尚未重启的宿主可能没有记录，其余内容仍可导出。

模块使用签名权限保护宿主日志请求，并限制请求时效和返回大小。宿主日志只保留在各进程内存中；要排查开盖或系统控制问题，更新后重新启动相应宿主，先复现问题再导出。所有时间戳使用 UTC。

设备蓝牙地址、标记的密钥和序列号、长十六进制身份值在进入日志缓冲区前脱敏。不会读取身份密钥存储、完整偏好、蓝牙抓包或其他应用的 logcat，也不需要 root 或网络上传。导出的文件由用户自行保存和分享。
