# 统一诊断日志与导出指南

为了在遇到连接异常、开盖失效或控制不生效时快速排查问题，HyperPods-X 提供了统一的诊断日志收集与脱敏导出机制。

---

## 1. 导出操作步骤

1. 在任意风格的控制面板中，进入 **“更多设置 → 导出日志”**；
2. 系统将调起文件选择器，指定保存位置后将生成 `HyperPods-X-logs-<时间戳>.zip` 压缩包；
3. 导出任务运行于独立后台协程，切换界面风格、旋转屏幕或退出页面不会中断写入过程。

---

## 2. 日志包结构说明

导出的 ZIP 压缩包包含以下调试文件：

| 文件 / 路径 | 说明 |
| --- | --- |
| `diagnostics.json` | 应用运行环境、当前系统版本、连接状态快照、电量及功能自检诊断信息 |
| `app-history.log` | 应用跨进程重启保留的历史运行日志（循环轮转，上限 1 MiB） |
| `app-session.log` | 当前前台进程最近的运行时调试日志（上限 64 KiB） |
| `hosts/` | 各被注入宿主（系统设置、小米蓝牙、设备互联）中本模块生成的运行时日志 |
| `collection-status.txt` | 各宿主日志抓取状态汇总，便于确认是否有宿主未就绪或未生效 |

---

## 3. 隐私与数据安全

- **严格数据脱敏**：设备物理 MAC 地址、配对密钥、设备序列号等敏感标识在写入日志缓冲区前均已自动哈希脱敏；
- **纯本地处理**：应用不申请网络权限，不收集第三方应用数据，所有排查日志仅保存在用户指定的本地目录，由用户完全自主掌控。
