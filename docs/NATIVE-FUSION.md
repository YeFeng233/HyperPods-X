# HyperOS 融合设备中心适配方案

HyperPods-X 支持将 AirPods 接入 HyperOS 控制中心内置的“融合设备中心”（设备互联），在系统耳机大卡片中直接展示耳机外观、实时电量，并支持直接控制聆听模式与空间音频。

---

## 1. 作用域与启用方式

- **LSPosed 作用域**：除“系统设置”（`com.android.settings`）与“小米蓝牙”（`com.xiaomi.bluetooth`）外，需勾选**“设备互联”**（`com.milink.service`）。
- **生效流程**：首次启用或更新模块后，可在 HyperPods-X 的“更多设置”中点击“重启作用域”，或直接重启手机。
- **使用条件**：AirPods 已配对并选定为当前媒体音频输出时，下拉系统控制中心即可看到耳机卡片。

---

## 2. 系统卡片交互与控制能力

### 2.1 外观与电量展示
- **独立型号外观**：系统默认对所有第三方或未识别 AirPods 使用同一张通用图标；HyperPods-X 拦截设备互联的图片加载逻辑，将卡片耳机图无缝替换为当前型号的高清正方形渲染图，并针对控制中心固定尺寸做了等比居中处理。
- **实时真实电量**：电量直接来自模块状态中心（Hub），真实反映左右耳与充电盒当前电量，避免显示为默认的 0% 或满电伪数据。

### 2.2 控制与手势集成
- **四档聆听模式**：卡片提供“关闭、通透、自适应、降噪”四个原生切换按钮，点击后通过 AACP 会话写入耳机，回读确认后同步更新高亮状态。
- **空间音频切换**：卡片上的空间音频按钮可直接在“关闭”与“固定空间音频”之间切换，状态与 App 内部完全同步。
- **更多设置跳转**：点击卡片内的“更多设置”，直接呼出 HyperPods-X 详情设置页，并保留用户当前选定的主题风格（miuix 或 iOS）。

## 3. 支持的耳机型号

基于统一的型号识别组件 `HeadsetModels`，完整支持以下 AirPods 官方型号编码：

| 产品名称 | 适配型号编码 |
| --- | --- |
| **AirPods 5（标准版）** | `A3531`、`A3532`、`A3533` |
| **AirPods 5（无线充电盒版）** | `A3439`、`A3440`、`A3441` |
| **AirPods Pro 3** | `A3063`、`A3064`、`A3065` |

## 4. 常见问题排查

### 卡片可打开，但图标与控制项退回系统默认蓝牙样式？
这通常是因为设备互联服务初始化时未能成功匹配耳机识别状态：
1. 打开 HyperPods-X，确保耳机已连接且成功读取到型号；
2. 在 App“更多设置”中点击“重启作用域”，授权重启设备互联宿主；
3. 重新下拉控制中心打开耳机卡片，即可恢复高清渲染图与四档控制按钮。

### 模块热重载与安全防护
- 模块支持现代 libxposed API 102 热重载。覆盖安装时框架会自动通知宿主卸载旧 Hook 并安装新逻辑；
- 当正在执行头部追踪、对话降音或写配置时，模块会安全延迟重载，保障现有会话不受干扰。
